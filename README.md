# Introduction to computational statistics course

## Table of contents

The course covers the basics of computational statistics and Monte Carlo simulation.

### [Lecture notes](https://github.com/sylvainlc/22_ComputationalStat/blob/main/Lecture/notes.pdf)

* Basics on Makov chains and Metropolis-Hastings algorithm
* Variants of Metropolis-Hastings algorithm (pseudo-marginal algorithm, Hamiltonian Monte Carlo)
* Variational inference and Coordinate Ascent Variational Inference (CAVI)
* Sequential Monte Carlo methods
* Bonus: reminder on M-estimation, Z-estimation, maximum likelihood
* Bonus: Latent data models and Expectation Maximization algorithm
